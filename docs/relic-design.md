# 가챠머신 서바이벌 — 유물 현황 및 추가 기획서

작성일: 2026-09-20 · 기준: 현재 저장소의 `index.html` · 상태: 구현 전 제안

## 1. 목적과 게임 전제

기존 유물 7종의 실제 동작을 정리하고, 생존·아이템 운용·강화 캡슐 활용에 새로운 선택지를 추가한다. 아래 신규 가격과 수치는 플레이테스트 전 가설이며, 이번 작업은 문서 작성 범위다.

- 한 게임은 3매치다. 상대는 차례로 1/2/3명, 목표 골드는 28/42/56이다. 목표 골드 달성 또는 최후 생존으로 승리한다.
- 시작 목숨은 2, 캡슐 재고는 30개다. 기본 투입 범위는 1~5개이며 재고가 최소 투입량보다 적으면 0개를 투입한다.
- 많은 캡슐 투입은 순위 골드를 주지만, 내 일반 캡슐이 뽑히면 목숨을 잃는다. 최소 투입자는 동률 모두 페널티 대상이다.
- 유물 상점은 **1·2매치 승리 후** 열린다. 패배 후 또는 최종 매치 승리 후 구매하는 구조가 아니다.
- 승리 시 머신에 남은 내 캡슐 수(일반+메탈+홀로그램)를 파편으로 받는다. 손에 남은 재고는 보상 계산에서 제외한다.
- 미보유 유물 중 최대 3종을 제시하며 리롤은 파편 1개다. 같은 유물 중복 구매는 불가하고, 장착 슬롯 제한은 없다. 구매한 유물은 다음 매치에 계승된다.
- 파편으로 일반 캡슐을 메탈(2개)·홀로그램(3개)으로 영구 강화할 수도 있다. 신규 유물은 이 선택과 경쟁해야 한다.
- 현재 AI는 유물 없이 시작하고 유물 상점을 이용하지 않는다. 신규 유물도 우선 플레이어 구매 대상으로 설계한다.

## 2. 현재 적용 유물 7종

가격 단위는 캡슐 파편이다. 설명문만이 아니라 발동 코드를 기준으로 정리했다.

### 코드 기준으로 드러난 정리 사항

1. **주머니 문구:** “아이템 종류별 최대 보유량이 3개에서 5개로 증가합니다”로 명확히 하는 것을 권장한다.
2. **불사조 문구:** “남은 재고에서 최대 4개를 추가합니다”로 실제 동작을 드러내는 것을 권장한다.
3. **골드 승리 판정:** 현재 목표 골드 검사는 투입 정산 뒤에 있다. 배당금·메탈 보상·판매 등으로 목표를 채운 즉시 항상 승리하는 구조는 아니다. 신규 골드 유물 구현 전에 판정 시점을 통일할 필요가 있다.
4. **상점 빈 슬롯 문구:** 현재 제시된 유물을 모두 사면 다른 미보유 유물이 남아도 “모든 유물을 이미 보유” 문구가 나올 수 있다. 신규 풀 확대 시 “현재 진열 상품을 모두 구매했습니다”와 전체 수집 완료를 구분한다.

## 3. 추가 설계 방향

현재 7종 중 직접 골드 획득이 3종, 투입 압박이 2종이다. 단순 골드 배율을 더하기보다 위험을 감수하는 방식과 아이템 사용 결정을 늘린다.

- 2~3매치에서 바로 체감할 수 있게 긴 누적 조건을 피한다.
- 영구 면역·반복 부활·무제한 환급은 도입하지 않는다.
- 캡슐을 제거하는 효과는 생존에는 유리하지만 배당금과 승리 파편에는 불리한 선택으로 만든다.
- 가격은 기존 5~9파편을 중심으로 설정한다. 조건부 편의는 5, 선택권 확대는 6, 직접 위험 제거는 7을 출발점으로 한다.
- 희귀도·장착 슬롯·새 재화는 이번 제안에 포함하지 않는다.

### 4.1 응급 정비 키트

**상점 문구:** “매치당 1회, 목숨을 잃고 살아남으면 머신 속 내 일반 캡슐을 최대 3개 제거합니다.”

- 실제 목숨 감소와 생존을 확인한 뒤, 기존 피격 보상 아이템 지급과 함께 처리한다. 현재 목숨 구조에서는 보통 2→1 피격 때 발동한다.
- 실드 방어·불사조 발동·메탈/홀로그램 재추첨에는 발동하지 않는다. 일반 캡슐이 0개면 사용 기회를 소모하지 않는다.
- 제거한 캡슐은 재고로 돌려주지 않는다. 강화 캡슐과 임시 추가분은 건드리지 않는다.
- 더블 뽑기에서는 첫 피격 후 즉시 제거하므로 두 번째 추첨의 풀에 반영한다.
- **차별점:** 불사조가 치명타를 막는다면 이 유물은 첫 피격 뒤 남은 위험을 줄인다. 둘을 보유해도 발동 조건은 분리된다.
- **검증:** 일반 캡슐 2개면 2개만 제거, 실드 방어 시 미소모, 다음 매치에서 사용 가능 횟수 복구.

### 4.2 단골 도장

**상점 문구:** “매 라운드 처음 구매하는 아이템의 가격이 1골드 감소합니다. 최소 가격은 1골드입니다.”

- 인게임 아이템 상점의 실제 구매 성공 시에만 소모한다. 리롤·판매·무료 지급·유물 및 영구 강화 구매는 제외한다.
- 표시 가격과 잔액 검증, 실제 차감에 동일한 할인가를 사용한다. 구매 실패 시 사용 기회를 유지한다.
- 같은 라운드에 상점을 다시 열거나 리롤해도 갱신하지 않는다. 종류별 한도와 동일 상품 구매 제한은 유지한다.
- 판매가는 원래 아이템 가격을 기준으로 유지한다. 할인으로 판매가가 변하지 않는다.
- **차별점:** 골드를 직접 늘리는 대신 소비 부담을 낮춘다. 골드 캡슐 구매에도 적용하되, 해당 아이템의 기존 순이익이 1 늘어나는 조합을 집중 측정한다.
- **검증:** 3골드 상품을 2골드로 구매, 두 번째 구매 정상가, 실패 후 할인 유지.

### 4.3 정밀 주입기

**상점 문구:** “메탈 캡슐화·홀로그램 캡슐화 아이템의 개별 강화 성공률이 75%가 됩니다.”

- 대상 최대 3개와 대상 선정 규칙은 유지한다. 각 대상별 독립 확률만 0.5→0.75로 바꾼다.
- 유물 상점의 확정 영구 강화에는 효과가 없다. 매치 안에서 아이템으로 바꾼 캡슐을 다음 매치의 영구 강화 수에 추가하지 않는다.
- **기대값:** 대상이 3개이면 사용당 평균 성공 수가 1.5→2.25개로 증가한다. 성공 3개를 보장하지 않는다.
- **차별점:** 직접 골드 없이 강화 아이템을 선택할 이유를 준다. 일반 캡슐이 부족하거나 강화 아이템을 얻지 못하면 가치가 낮다.
- **검증:** 일반 캡슐 0/1/3개 조건, 75% 경계값, 비소유자의 50% 유지, 영구 강화 데이터 불변.

### 4.4 재활용 집게

**상점 문구:** “매 라운드 페널티로 내 캡슐이 실제 투입되면, 1회에 한해 랜덤 아이템 1개를 획득합니다.”

- 최소 투입 동률도 포함한다. 페널티가 예정돼도 재고 소진으로 실제 추가량이 0이면 발동하지 않는다.
- 가혹한 형벌로 2개를 넣어도 보상은 1개다. 자발적 투입과 아이템에 의한 추가 투입은 제외한다.
- 종류별 한도 미만인 아이템 중 균등 추첨한다. 전 종류가 가득 차면 보상 없이 종료하고 다음 라운드로 이월하지 않는다.
- 기존 랜덤 아이템 지급 규칙을 재사용하되 로그 원인을 “피격 보상”과 구분한다.
- **차별점:** 낮게 베팅하는 플레이의 위험을 없애지 않고 아이템 운용 기회를 준다. 최소 투입이 항상 최선이 되면 가격을 6으로 올리거나 매치당 발동 상한을 검토한다.
- **검증:** 동률 최소 투입, 실제 페널티 0개, 형벌 동시 보유, 전 종류 최대 보유.

### 4.5 비상 배출 레버

**상점 문구:** “매치당 1회 사용: 추첨 전에 머신 속 내 일반 캡슐을 최대 4개 제거합니다.”

- 기존 아이템 사용 단계에 별도의 유물 사용 버튼을 둔다. 제거 가능한 기본 일반 캡슐이 1개 이상일 때만 활성화한다.
- 임시 캡슐·강화 캡슐은 제외한다. 제거분은 재고로 반환하지 않으며, 기본 머신의 소유자 기준으로 처리한다.
- 투시 사용 뒤에도 사용할 수 있으나 기존 투시 결과를 무효화하고 “머신 구성이 바뀌어 예측이 초기화되었습니다”를 표시한다. 풀 변경 후 이미 정해진 결과를 그대로 사용하면 안 된다.
- 삼중 부적·뒤바꿈 효과는 제거 후 풀에서 다시 계산한다. 유물 자체는 파괴되지 않고 다음 매치에 1회 충전된다.
- **차별점:** 응급 키트와 달리 선제적으로 위험을 줄인다. 배당금·승리 파편 감소가 비용이다.
- **검증:** 이중 클릭 방지, 일반 0개에서 미소모, 투시 초기화, 뒤바꿈과 부적 동시 적용.

### 4.6 홀로그램 카탈로그

**상점 문구:** “내 홀로그램 캡슐이 뽑히면, 랜덤 아이템 대신 제시된 최대 3종 중 1개를 선택합니다.”

- 종류별 한도 미만인 서로 다른 아이템을 최대 3종 추출한다. 선택을 완료한 뒤 기존 재추첨을 진행한다.
- 후보 1종이면 자동 지급, 0종이면 보상 없이 재추첨한다. 골드 대체 보상은 없다.
- 피격·재활용 집게의 보상에는 적용하지 않는다. 대용량 주머니로 늘어난 종류별 한도를 반영한다.
- 더블 뽑기나 연속 홀로그램 추첨도 횟수별로 처리하되 후보 창을 동시에 여러 개 열지 않는다.
- **차별점:** 보상량을 늘리지 않고 필요한 아이템을 고르는 권한을 준다. 선택 화면 구현이 필요하므로 P2로 둔다.
- **검증:** 후보 0/1/2/3종, 한도 초과 지급 방지, 선택 중 손잡이 입력 잠금, 연속 재추첨 정상 진행.

### 4.7 금속 공명기

**상점 문구:** “매 라운드 처음 뽑힌 내 메탈 캡슐은 7골드를 줍니다. 이후에는 기본 5골드를 줍니다.”

- 실제 추첨된 메탈 캡슐 소유자를 기준으로 한다. 투시로 확인만 한 경우 발동하지 않는다.
- 연속 재추첨과 더블 뽑기를 합쳐 라운드당 +2골드 상한이다. 골드로 승리하면 추가 재추첨을 종료한다.
- **차별점:** 황금 주사위의 투입 순위 보상과 달리 강화 캡슐이 필요하고 추첨 여부에 의존한다.
- **밸런스:** 메탈 강화 2개(4파편)와 직접 비교한다. 메탈 확보 전에는 효과가 없다는 조건을 상점에서 안내한다.
- **검증:** 같은 라운드 두 번 추첨하면 7+5골드, 다음 라운드 재충전, 상대 메탈에 미발동.

### 4.8 보험 약관

**상점 문구:** “매치당 1회, 하트 실드로 피해를 막으면 다음 라운드 시작에 3골드를 받습니다.”

- 실드 아이템을 사용한 시점이 아니라 실드가 실제 소모되어 피해를 막은 때 보상을 예약한다.
- 다음 라운드에도 소유자가 생존한 경우 지급한다. 더블 뽑기의 후속 피해로 탈락하거나 매치가 먼저 끝나면 예약은 소멸한다.
- 불사조·부적·빈 캡슐·강화 캡슐 결과 무효화는 보험 대상이 아니다. 실드를 다시 얻어도 매치당 한 번만 예약한다.
- **차별점:** 방어 횟수를 늘리지 않고 실제 방어 성공의 기회비용을 일부 보전한다. 4골드 실드 가격보다 작은 보상을 지연 지급한다.
- **검증:** 실드만 사용하고 피격되지 않으면 예약 없음, 두 번째 추첨 탈락 시 지급 없음, 이어하기 중복 지급 없음.

## 5. 공통 구현 규칙

### 상태와 적용 순서

- 신규 상태는 플레이어별 `relicState` 아래 둔다. 매치 사용 여부(키트·레버·보험), 라운드 사용 번호(도장·집게·공명기), 보험 예약 라운드를 저장한다.
- 신규 매치에서는 사용 상태를 초기화하고 소유 유물 ID만 계승한다. 기존 불사조의 파괴 규칙은 유지한다.
- 같은 라운드를 다시 렌더링하거나 이어하기해도 충전·보상을 반복하지 않는다. 구버전 저장에 없는 상태는 기본값으로 보정한다.
- 현재 저장은 라운드 체크포인트 방식이다. 우선 동일 체크포인트 복귀 기준으로 상태 일관성을 보장한다. 카탈로그 선택 중 임의 시점 복원을 지원하려면 후보와 추첨 진행 상태 저장을 별도로 구현해야 한다.
- 판정 순서: 실제 추첨 결과 확정 → 실드 → 치명타일 때 불사조 → 실제 피해와 생존 확인 → 기존 피격 보상 및 정비 키트. 실드 소모 시에는 보험 예약만 처리한다.

### 골드 승리 판정 정리 제안

현재 동작과 구분되는 **변경 제안**이다. 골드 추가 후 안전한 처리 경계에서 공통 승리 검사를 호출한다.

- 투입 단계는 모든 참가자의 순위·유물 보상 및 페널티 처리가 끝난 뒤 판정한다. 동시 달성은 현재 플레이어 배열 순서의 우선권을 유지하고 규칙에 명시한다.
- 라운드 시작은 배당금·보험 지급을 모두 마친 뒤, 투입 UI를 열기 전에 판정한다.
- 메탈 보상은 지급 후 재추첨 전에, 판매와 즉시 골드 아이템은 효과 처리 직후 판정한다.
- 종료 플래그로 중복 종료를 막고 열린 상점·선택창과 대기 중 추첨 흐름을 정리한다. 별도 변경으로 검증한 뒤 신규 골드 유물을 연결한다.

### 표시와 자산

- 카드에는 발동 조건과 “라운드당/매치당” 제한을 반드시 표시한다. 조건부 강화 유물에는 현재 준비 상태를 짧게 표시한다.
- 소유 유물 상세에서 “사용 가능/이번 매치 사용 완료/다음 라운드 3골드” 상태를 확인할 수 있어야 한다.
- 발동 로그는 `[유물명] 조건 → 실제 효과` 형식으로 남긴다. 요청 수량이 아닌 실제 제거·지급 수량을 출력한다.
- `RELIC_ICON_CELL`과 스프라이트 자산을 함께 확장한다. 현재 4×4 좌표 체계에서 ID 7개가 매핑되어 있지만, 미사용 셀에 신규 그림이 준비되어 있다는 뜻은 아니다. 신규 그림 확정 전에는 명시적 임시 아이콘을 사용한다.

## 6. 구현 단계와 검증 계획

### 1차: P1 4종

응급 정비 키트 → 단골 도장 → 정밀 주입기 → 재활용 집게 순으로 추가한다. 공통 상태 저장과 발동 로그도 함께 도입한다. 기존 7종에서 총 11종이 된다.

### 2차: P2 4종

골드 승리 판정 정리 후 금속 공명기·보험 약관을 추가한다. 풀 변경과 투시 무효화를 검증한 뒤 레버, 선택 UI가 필요한 카탈로그를 추가한다. 전체 제안 적용 시 총 15종이다.

### 밸런스 확인

아래는 측정 계획이며 검증 완료 결과가 아니다.

| 확인 대상 | 기록 지표 | 조정 판단 |
|---|---|---|
| 구매 가치 | 등장·구매 횟수, 가격 때문에 구매하지 못한 횟수 | 자주 노출되지만 선택되지 않는 유물은 조건·가격 재검토 |
| 생존 효과 | 발동 횟수, 제거한 일반 캡슐 수, 보유/미보유 승률 | 키트+레버+불사조가 생존 선택을 고정하면 제거량 또는 가격 조정 |
| 경제 효과 | 유물별 추가 골드·할인 합계, 목표 달성 라운드 | 주사위·배당금과 결합해 지나치게 빨리 종료하면 발동 상한 검토 |
| 베팅 변화 | 최소 투입 비율, 집게 보상 후 아이템 사용률 | 집게 보유 시 최소 투입만 반복하는 전략이 우세하면 하향 |
| 강화 선택 | 유물 구매와 직접 영구 강화의 선택 비율 | 공명기·주입기가 직접 강화보다 항상 유리하거나 무의미한지 확인 |
| 풀 확대 | 원하는 유물 노출률, 리롤 파편 소모 | 후보 3종 유지 시 탐색 비용 증가를 확인한 뒤 진열 변경 판단 |

같은 초기 상태와 난수 시드를 사용할 수 있는 검증 환경을 마련해 무유물·단일 유물·주요 조합을 비교한다. 자동 시뮬레이션은 현재 저장소에 없는 후속 작업이며, 초기에는 매치 2·3 수동 플레이로 발동과 선택의 체감을 확인한다.

### 필수 회귀 시나리오

- 재고 0개, 최소량 미만, 최소 투입 동률, 모든 아이템 종류 보유 한도 도달.
- 더블 뽑기 첫 피격→키트→두 번째 추첨, 실드→보험 예약→두 번째 추첨 탈락.
- 레버+투시+부적+뒤바꿈, 집게+가혹한 형벌, 카탈로그+대용량 주머니.
- 메탈 연속 추첨 중 목표 골드 달성 시 매치 종료 및 후속 추첨 중단.
- 저장 후 이어하기에서 발동 횟수와 예약 보상 유지, 다음 매치에서는 충전 복구.
- 유물 구매·리롤·다음 매치 계승, 불사조 소모 후 계승 목록에서 제외.

## 7. 조사 근거

행 번호는 작성 시점의 `index.html` 기준이다. 이후 코드 변경 시 함수명과 ID로 다시 확인한다.

| 확인 내용 | 위치 |
|---|---|
| 매치 목표·유물·아이템·영구 강화 데이터 | `index.html:922–1003` |
| 시작 목숨·재고·유물 계승 | `freshPlayers`, `newMatch` / 1274–1333 |
| 저장 및 구버전 보정 | `saveGame`, `loadGame` / 1350–1398 |
| 일반·강화 캡슐 계산 및 부적·뒤바꿈 | `getEffectivePool`, `countPlayerOwnCapsules` / 1815–1845 |
| 배당금·행운 목표 생성 | `beginRound` / 2067–2086 |
| 사슬·최소 투입·순위·형벌·주사위 | `computeMinFloor`, `applyBetsToMachine` / 2188–2441 |
| 종류별 아이템 한도·구매 처리 | `renderPopupShopUI` / 2501–2533 |
| 유물 3종 진열·구매·리롤·계승 | `rollRelicShopOffer` 등 / 2598–2698 |

| 상점 진입 조건과 파편 정산 | `finishMatch` / 3529–3565 |

조사 방식: 데이터 정의 및 효과 호출부 정적 검토. 실제 브라우저 플레이나 신규 효과 구현·밸런스 실험은 수행하지 않았다.
