# 가챠머신 서바이벌 — 영구 캡슐 강화 현황 및 확장 기획서

작성일: 2026-09-20 · 기준: 현재 저장소 `index.html` · 상태: 구현 전 제안

관련 문서: [유물 기획서](relic-design.md), [아이템 기획서](item-design.md)

## 1. 핵심 결론과 범위

현재 영구 강화는 일반 캡슐을 **메탈·홀로그램 2종**으로 바꾸는 확정 구매 시스템이다. ‘영구’는 **한 번의 3매치 도전 안에서 다음 매치로 계승**된다는 뜻이며, 새 도전까지 유지되는 계정 성장 기능은 없다.

확장 방향은 보상 수치만 높이는 강화 단계보다 캡슐 구성의 역할을 늘리는 것이다. **신규 캡슐 3종과 구성 관리 기능 2종**, 총 5개 요소를 제안한다. 기존 30개 구성과 파편 재화는 유지한다. 아래 가격·상한은 플레이테스트 전 제안값이며, 기존 유물·아이템 문서의 신규안 역시 미구현 상태다.

## 2. 현재 시스템 분석

### 2.1 구매부터 계승까지

| 단계 | 현재 동작 | 의미 |
|---|---|---|
| 첫 매치 | 일반 30개로 시작 | 최초 도전부터 강화 구성을 고르는 기능 없음 |
| 상점 진입 | 1·2매치 승리 후 유물 상점에서 강화 구매 | 한 도전의 강화 구매 기회는 최대 2회 |
| 재화 정산 | 기존 파편 + 승리 시 머신에 남은 내 일반·메탈·홀로그램 수 | 손의 재고, 이미 뽑힌 캡슐, 임시 추가분은 정산 제외 |
| 구매 대상 | 다음 매치 구성의 일반 캡슐 1개 | 직전 매치에 남은 특정 실물 1개를 고르는 구조가 아님 |
| 성공률 | 파편 차감 후 100% 강화 | 아이템 강화의 50% 확률과 별개 |
| 진열 | 메탈·홀로그램 강화는 상시 제시 | 유물 3종 무작위 진열·리롤에 영향받지 않음 |
| 구매 횟수 | 파편 및 구성상 일반 캡슐이 남으면 반복 가능 | 종류별 레벨·구매 횟수 제한 없음 |
| 구성 한도 | 메탈+홀로그램 ≤30, 나머지가 일반 | 30개 전부 강화하는 것도 데이터 규칙상 허용 |
| 새 매치 | 저장된 구성으로 총 30개 재고를 새로 생성 | 이전 매치에서 뽑히거나 청소된 강화 캡슐도 다시 공급 |
| 최초 투입 | 각 참가자의 재고에서 무작위 1개를 머신에 투입 | 시작 직후 재고 29개+머신 1개. 강화 종류를 보장하지 않음 |
| 일반 투입·페널티 | 남은 재고의 종류별 수량 비례 무작위 추출 | 사용자가 일반·강화 중 넣을 종류를 선택하지 못함 |
| 추첨 | 강화 캡슐 실물 1개 소모 → 보상 → 결과 무효화 후 재추첨 | 매치 중 재고로 돌아가지 않지만 영구 구성 기록은 유지 |
| 새 도전 | 계승값 없이 초기화 | 강화·파편을 다음 도전까지 보존하지 않음 |
| AI | 일반 30개로 시작, 영구 강화 구매 없음 | 다만 매치 중 아이템으로 메탈·홀로그램을 만들 수 있음 |

### 2.2 현재 강화 2종

| 종류 / ID | 파편 | 추첨 효과 | 제한·특징 |
|---|---:|---|---|
| 메탈 / `metal` | 2 | 생존 소유자에게 5골드, 해당 결과를 무효화하고 재추첨 | 피해 없음. 동일 캡슐은 소비되어 같은 매치에서 다시 뽑히지 않음 |
| 홀로그램 / `holo` | 3 | 생존 소유자에게 랜덤 아이템 1개, 결과 무효화 후 재추첨 | 종류별 한도 미만인 후보 중 지급. 모든 종류가 가득 차면 아이템 없이 재추첨 |

메탈은 빠른 골드 승리, 홀로그램은 아이템 확보를 지원한다. 둘 다 위험한 일반 캡슐을 대체하지만, **강화 결과 자체가 유효 추첨 1회를 안전하게 끝내는 것은 아니다.**

### 2.3 확률을 설명할 때 구분할 값

강화 비율과 생존 확률을 같은 숫자로 표시하면 안 된다.

- 다음 투입 1개가 강화일 확률은 `재고의 강화 수 / 전체 재고 수`다. 머신에 이미 들어간 개수는 이 계산에서 제외한다.
- 첫 물리적 추첨의 피격 확률은 `현재 유효 내 일반 수 / 전체 추첨 풀`이다.
- 강화 결과의 재추첨까지 고려한 최종 피격 확률은 다르다. 풀 변경·실드·승리 종료 등이 없고, 유효 종료 결과가 일반·빈뿐이라면 `내 일반 수 / (모든 일반 수 + 빈 수)`로 계산할 수 있다.

예를 들어 내 일반 3, 상대 일반 5, 빈 2, 재추첨형 강화 2개이면 첫 피격 확률은 3/12=25%지만, 강화 재추첨을 거친 유효 결과의 내 피격 확률은 3/10=30%다. 여기서 내 일반 1개를 메탈로 바꾸면 최종 피격 확률은 2/9≈22.2%로 낮아진다. 즉, 실제 방어 가치는 일반 캡슐을 줄이는 데 있고, 재추첨형 캡슐을 분모에 추가하는 것만으로 설명할 수 없다.

이 예시는 고정 풀의 단일 유효 추첨 분석이다. 더블 뽑기, 부적, 탈락자 처리, 보상으로 인한 즉시 승리, 신규 캡슐의 지연 효과가 있으면 그대로 적용하지 않는다.

### 2.4 영구 구성과 매치 중 변환의 구분

| 구분 | 영구 강화 상점 | 메탈·홀로그램 캡슐화 아이템 |
|---|---|---|
| 지불 | 파편 2/3개 | 아이템 사용, 상점 원가 각 5골드 |
| 대상 | 다음 매치 기본 구성의 일반 1개 | 현재 머신의 내 일반 최대 3개 |
| 성공 | 확정 | 각 대상 50% |
| 기록 | `capsuleUpgrades` 변경 | `G.machine`만 변경 |
| 다음 매치 | 강화 수대로 새 재고 지급 | 변환 수가 영구 구성에 추가되지 않음 |

예: 영구 메탈 2개를 가진 채 시작한 매치에서 아이템으로 메탈 3개를 더 만들고 모두 뽑혔더라도, 다음 매치는 영구 메탈 2개로 다시 시작한다.

## 3. 현재 구조의 한계와 선행 정리

1. **지속 범위 문구:** 상점에 “이번 도전의 다음 매치에도 유지됩니다. 새 도전에서는 초기화됩니다”를 명시한다. 계정 영구 성장으로 오해하지 않게 한다.
2. **효과 체감 지연:** 강화 1개는 시작 시 1/30 확률로 투입된다. 재고에 남아 매치가 끝나면 아무 보상도 주지 못한다. 캡슐을 여러 개 투입할수록 강화 노출도 늘지만 일반 위험도 함께 늘어난다.
3. **중간 상점 저장 공백:** `finishMatch`는 기존 저장을 지우고, 강화 구매는 메모리의 `nextMatchCarryState`만 수정한다. 상점 구매 직후 새로고침하면 구성과 파편을 복구할 저장 경로가 현재 없다. 확장 전에 상점 상태 저장을 권장한다.
4. **상태 표시 혼합:** 캡슐 서랍은 재고만 ‘보유’, 머신 안과 이미 소비한 캡슐을 모두 ‘비활성’으로 표시한다. 아이템 변환과 영구 구성이 섞이면 종류별 소모량을 추정하는 방식도 정확한 실물 이력과 다를 수 있다.
5. **종류 하드코딩:** 재고·투입·추첨·청소·표시·계승 정규화가 일반/메탈/홀로그램에 맞춰 작성돼 있다. 데이터 배열에 새 종류만 추가해서는 정상 동작하지 않는다.
6. **구버전 보정:** 개별 재고 종류를 0~30으로 제한하지만 전체 합계 검증은 별도다. 재고 정보가 없는 저장은 머신의 총량을 일반 재고에서만 빼므로 강화별 실물 수를 정확히 복원하지 못할 수 있다. 현재 저장 경로의 정상 동작과 구버전 복구 한계를 구분한다.
7. **추첨 종료:** 강화 보상 직후 골드 승리 검사와 탈락자 캡슐 소모를 함께 정리해야 한다. 현재 탈락자 결과는 소모 전에 재추첨으로 돌아가므로 비활성 소유자만 남은 풀 등에서 반복될 여지가 있다.
8. **낮은 가격의 반복 강화:** 메탈 3개와 6파편 유물은 같은 예산을 쓴다. 유물 확장과 별도로 강화가 항상 최선인지 비교해야 한다. 당장 기존 가격을 올리는 것을 전제로 하지는 않는다.

## 4. 신규 요소 5개 요약

신규 종류는 영구 구성의 일반 1개를 대체한다. 예외를 따로 적지 않은 구매는 확정 성공이며, 다음 매치부터 적용된다.

| 우선순위 | 요소 / ID | 파편 | 효과·용도 | 구현량 |
|---|---|---:|---|---|
| P1 | 세라믹 캡슐 / `ceramic` | 3/개 | 피해·보상 없이 해당 유효 추첨을 안전하게 종료 | 중 |
| P2 | 완충 캡슐 / `cushion` | 3/개 | 다음 라운드에 내 일반 캡슐 1개를 빈 취급 예약, 현재는 재추첨 | 중 |
| P2 | 회수 코어 / `salvage` | 2/개 | 다음 상점으로 진행하는 승리 시 파편 +2 예약, 현재는 재추첨 | 중 |
| P1 | 강화 재설정 / `reforge` | 규칙식 | 영구 강화 1개를 다른 종류로 변경 | 중 |
| P2 | 시작 투입 슬롯 / `opening_slot` | 4/도전 | 매치 시작의 기존 1개 투입 종류를 지정 | 중 |

신규 종류별 영구 구성 상한은 세라믹 4개, 완충 3개, 회수 코어 3개로 시작한다. 메탈·홀로그램은 현재 한도를 유지한다. 모든 종류 합계는 30개다. 이는 실험용 신규 종류의 과도한 누적을 제한하기 위한 초안이며, 무적이나 승률을 수학적으로 보장하는 상한은 아니다.

### 4.1 세라믹 캡슐 — 보상 대신 추첨 종료

**상점 문구:** “일반 캡슐 1개를 세라믹으로 바꿉니다. 뽑히면 피해 없이 이번 추첨 1회를 마칩니다. 보상과 재추첨은 없습니다.”

- 소유자가 살아 있으면 실물 1개를 소모하고 안전한 유효 결과로 처리한다.
- 더블 뽑기에서 첫 결과가 세라믹이면 두 번째 추첨은 정상 진행한다. 라운드 전체를 종료하는 효과가 아니다.
- 골드·아이템·목숨 회복을 주지 않고 실드·불사조도 소모하지 않는다.
- 소유자가 탈락했다면 다른 탈락자 캡슐과 같은 규칙으로 제거 후 재추첨한다. 누구 소유인지 표시하되 효과는 모두에게 안전하다.
- **차별점:** 메탈·홀로그램은 보상을 받고 계속 뽑는다. 세라믹은 보상을 포기하고 추첨을 멈춘다. 상대를 제거하려는 전략에는 불리할 수도 있다.
- **확률 예:** 위의 내 일반 3·상대 일반 5·빈 2에서 내 일반 1개를 세라믹으로 바꾸면 유효 피격 확률은 2/(2+5+2+1)=20%다. 메탈 전환의 2/9와 역할이 다르다.
- **조합:** 기존 배당금 및 승리 파편에는 내 소유 캡슐로 포함한다. 제안 아이템 공회전 필터는 기본 빈 캡슐만 제거하므로 세라믹에 영향이 없다.
- **검증:** 더블 뽑기 1회만 소모, 실드 보존, 전원 세라믹만 있는 비어 있지 않은 풀, 탈락 소유자 처리.

### 4.2 완충 캡슐 — 다음 라운드 방어 예약

**상점 문구:** “뽑히면 다음 라운드에 내 일반 캡슐 1개를 빈 캡슐로 취급합니다. 현재 결과는 무효화하고 재추첨합니다. 예약은 최대 2개입니다.”

- 실물 1개를 소모하고 소유자의 다음 라운드 완충 예약 +1, 상한 2. 상한 도달 후 추가로 뽑히면 예약은 늘지 않지만 실물 소모와 재추첨은 진행한다.
- 다음 라운드 아이템 단계의 임시 효과 상태를 만들 때 시작 예약을 기본 부적 수량으로 적용한다. 이후 아이템으로 추가된 일반 캡슐에도 기존 부적 계산과 동일하게 적용한다.
- 일반 캡슐이 부족하면 있는 수만 빈 취급한다. 남는 보호 수량은 이월하지 않고 그 라운드 종료 시 소멸한다.
- 이번 추첨의 위험을 즉시 막지는 않는다. 같은 라운드의 후속 추첨에서 소유자가 탈락하면 예약은 소멸한다. 매치가 끝나도 다음 매치로 예약을 넘기지 않는다.
- **조합:** 삼중 부적의 현재 효과 2개와 합산 가능. 뒤바꿈 전에 계산한다. 제안 정밀 주입기·금속 공명기·홀로그램 카탈로그는 적용하지 않는다.
- **상태 표시:** “다음 라운드 완충 1/2”와 “이번 라운드 완충 적용 1”을 구분한다.
- **검증:** 3개 연속 추첨 시 예약 2, 재개 시 중복 지급 금지, 일반 0개, 현재 라운드 탈락, 다음 매치 초기화.

### 4.3 회수 코어 — 다음 상점 투자

**상점 문구:** “뽑히면 다음 상점으로 진행하는 승리 시 받을 파편 2개를 예약합니다. 현재 결과는 무효화하고 재추첨합니다. 매치당 예약 최대 6개.”

- **1매치 승리 후 상점에서만 신규 구매 가능.** 2매치에서 효과를 보고 다음 상점에 도달하는 투자를 위한 종류다. 최종 매치에는 새 파편의 사용처가 없으므로 신규 구매를 노출하지 않는다.
- 실물 소모 뒤 `pendingWinFragments`에 +2, 매치당 최대 6. 즉시 쓸 수 있는 파편이나 골드를 주지 않는다.
- 2매치 승리 정산: 기존 잔여 파편 + 머신 잔존 내 캡슐 수 + 예약 파편. 뽑힌 코어는 이미 머신에서 제거되어 잔존 수와 중복 계산하지 않는다.
- 뽑히지 않고 머신에 남은 코어는 다른 내 캡슐처럼 1파편만 정산한다. 재고에 남은 코어는 정산하지 않는다. 패배 시 예약은 소멸한다.
- 2매치 승리 후에는 재설정으로 다른 종류로 바꾸는 안내를 보여준다. 코어를 유지하고 최종 매치로 가면 피해 없이 재추첨만 하며 파편 예약은 하지 않는다고 명시한다. 자동 전환은 하지 않는다.
- **경제 예:** 2파편을 지불한 코어가 2매치에서 뽑히고 승리하면 2파편 예약을 받는다. 다음 상점에서 메탈로 재설정하려면 추가 1파편이 필요하다. 뽑히지 않거나 패배하면 이 예산 회수는 성립하지 않는다.
- **차별점:** 현재 매치 승리에 필요한 골드·아이템 대신 후속 구성 예산을 선택한다. 짧은 도전 구조 때문에 효용이 제한되어 P2로 둔다.
- **검증:** 남음/소비/재고의 정산 분리, 예약 상한, 패배, 최종 매치 비활성, 상점 재진입 중복 정산 방지.

### 4.4 강화 재설정 — 이미 산 구성을 바꾸는 기능

**상점 문구:** “영구 강화 1개를 다른 종류로 바꿉니다. 총 캡슐 수는 그대로 유지됩니다.”

- 매치 사이 상점에서만 제공한다. 원본 종류 1개를 줄이고 대상 종류 1개를 늘린다. 같은 종류로 변경·일반으로 되돌리기·파편 환불은 지원하지 않는다.
- 비용은 `1 + max(0, 대상 기본 강화 가격 - 원본 기본 강화 가격)`파편이다. 원본 구매 당시 할인·가격 이력은 사용하지 않는다.
- 예: 메탈(2)→홀로그램(3)은 2파편, 홀로그램→메탈은 1파편, 메탈→회수 코어(2)는 1파편이다. 왕복해도 파편을 얻지 못한다.
- 신규 종류 상한과 구매 가능 시점을 동일하게 검사한다. 따라서 2매치 승리 후에는 다른 종류→회수 코어도 불가하지만 코어→다른 종류는 가능하다.
- 해당 매치에서 뽑혔거나 청소된 원본도 영구 구성에 있으면 변경 가능하다. 매치 안의 현재 실물이 아닌 다음 매치 구성을 편집하는 기능이다.
- **차별점:** 제안 아이템 위상 변환기는 현재 머신의 메탈↔홀로그램만 바꾸며 영구 기록은 유지한다. 재설정은 다음 매치 구성 자체를 변경한다.
- **검증:** 부족한 파편, 없는 원본, 대상 상한, 30개 전부 강화 상태에서도 변환 가능, 왕복 후 총량 동일 및 재화 감소.

### 4.5 시작 투입 슬롯 — 적은 강화 수량의 체감 개선

**상점 문구:** “매치 시작에 투입되는 내 캡슐 1개의 종류를 지정할 수 있습니다. 지정한 캡슐은 기존 재고에서 꺼냅니다.”

- 상점에서 4파편으로 도전당 1회 해금한다. 해금 상태는 다음 매치에 계승하며 새 도전에서는 초기화한다. 슬롯은 1개, 추가 확장 없음.
- 다음 매치 구성에 존재하는 종류 중 하나 또는 ‘무작위’를 선택한다. 기본 선택은 무작위다. 지정한 종류 재고 1개를 차감해 시작 머신에 투입한다.
- 시작 투입 총수는 기존과 같은 1개다. 추가 생성·무료 투입·순위 골드·행운 적중은 제공하지 않는다. 일반 베팅과 페널티는 계속 무작위 재고 추출이다.
- 재설정으로 지정 종류가 0개가 되면 무작위로 되돌리고 안내한다. 저장 복원에서도 같은 검증을 적용한다.
- **효용:** 강화가 재고에만 남는 일을 줄인다. 강화 결과가 실제로 뽑히는 것까지 보장하지 않으며, 최초 투입 뒤 청소로 제거될 수 있다.
- **비용 비교:** 메탈 1개+슬롯은 6파편, 메탈 3개도 6파편이다. 소수 종류의 조기 노출을 보장할지, 전체 강화 밀도를 높일지 선택한다.
- **경계:** 슬롯+코어로 예약 파편을 반드시 받는 것은 아니다. 슬롯+세라믹도 상대가 안전해질 가능성을 함께 늘린다.
- **검증:** 지정 시 재고 29+머신 1 유지, 중복 해금 구매 방지, 원본 0개 보정, 다음 매치 계승 및 새 도전 초기화.

## 5. 상점과 캡슐 현황 UI

### 상점 구성

기존 유물 상점 안에서 ‘캡슐 구성’ 영역을 분리하고 다음을 한 화면에서 비교한다.

- 다음 매치의 총 30개 구성: 일반/메탈/홀로그램/신규 종류별 수량.
- 일반에서 새 강화로 전환, 기존 강화에서 재설정, 시작 투입 슬롯 해금·선택.
- 각 행동의 파편 비용, 구매 후 잔액, 종류별 상한, 현재 구매할 수 없는 이유.
- 강화 카드에 **“추첨 종료” 또는 “보상 후 재추첨”**을 표시해 효과를 구분한다.
- 회수 코어는 “다음 상점이 있는 매치 전용”을 표시하고, 최종 매치 진입 전 현재 보유 코어의 재설정 안내를 제공한다.

구매와 재설정은 성공 즉시 저장한다. ‘다음 매치 시작’은 별도의 실행 단계로 유지한다. 취소·환불을 추가할 경우에는 개별 거래의 비용 차이를 이용한 이득이 생기지 않도록 별도 설계가 필요하므로 이번 범위에서는 도입하지 않는다.

### 매치 중 현황

현재 서랍의 ‘보유/비활성’ 대신 **다음 매치 기본 구성 / 현재 재고 / 머신 안 / 이번 매치 소비·제거 수**를 구분한다. 아이템으로 바뀐 현재 종류를 영구 강화 수로 오해하지 않도록 기본 구성은 별도 행에 표시한다.

슬롯 선택은 상점에서만 수정하며, 매치 중에는 시작 투입 기록만 볼 수 있다. 완충·코어의 예약 효과는 현재 캡슐 수와 별도로 표시한다.

## 7. 데이터·구현 설계

### 구성과 현재 실물의 분리

새 구조는 종류 정의를 공통 목록으로 관리한다. 다음 예시는 스키마 방향이며 실행 코드가 아니다.

```json
{
  "version": 2,
  "capsuleBlueprint": {
    "metal": 2,
    "holo": 1,
    "ceramic": 1,
    "cushion": 0,
    "salvage": 0
  },
  "openingSlot": { "unlocked": true, "kind": "metal" }
}
```

- 일반 수량은 `30 - 모든 강화 구성 수`로 계산한다. 예시 구성은 일반 26개다.
- 종류 정의에는 이름·아이콘·기본 파편 가격·구성 상한·구매 가능 매치·유효 추첨 종료 여부·보상 핸들러를 둔다.
- `stockByKind`, `machineByKind`, `consumedByKind`는 현재 매치 실물 상태다. 영구 구성에서 현재 종류별 소비량을 역산하지 않는다.
- 정상 시작과 투입에서는 실물 총량을 보존하고, 추첨·청소에서는 소비/제거 기록으로 이동한다. 종류 전환 시 총량을 보존한다. 임시 함정 캡슐은 30개 실물과 별도 장부다.
- 정상 플레이에서 아이템 종류 전환이 있을 수 있으므로 현재 메탈 수가 영구 메탈 수보다 많다는 이유만으로 잘라내지 않는다.
- `nextRoundCushion`과 `pendingWinFragments`는 현재 매치 상태로 두고 다음 매치 구성에 복사하지 않는다.

### 처리 순서

1. 추첨 후보에 실제 소유자·종류·출처를 담는다. 탈락 소유자의 결과라면 해당 실물을 제거하고 재추첨한다.
2. 생존 소유자의 실물 1개를 소비 기록으로 이동한다.
3. 종류에 따라 보상·예약 또는 일반 피해를 처리한다. 세라믹은 피해 없이 유효 결과 종료다.
4. 골드 목표 등 매치 종료 조건을 확인한다. 종료된 경우 후속 재추첨·더블 뽑기를 진행하지 않는다.
5. 강화 재추첨이면 남은 풀로 다시 계산한다. 후보가 없으면 안전하게 유효 추첨을 끝내어 무한 루프를 막는다.
6. 라운드가 계속되면 완충 예약을 다음 라운드 시작 상태로 확정하고, 해당 라운드 임시 효과 생성 시 한 번만 반영한다.

현재 아이템 문서에서 지적한 임시 캡슐 출처 추적과 함께 정리해야 이중 추첨에서 동일한 가상 캡슐을 반복 사용하는 문제를 피할 수 있다.

### 저장·복원

- 진행 단계(`match`/`intermission`)를 저장한다. 상점 상태에는 다음 매치 번호·파편·유물 제시 목록·소유 유물·강화 구성·슬롯을 포함한다.
- 정산은 상점 진입 시 재계산하지 않고 승리 처리에서 한 번 확정한다. 저장된 정산 결과를 복원한다.
- 각 거래는 자원·구성 검증→새 상태 계산→차감과 구성 변경을 함께 확정→저장 순서로 처리한다. 연속 클릭과 잔액 부족을 실행부에서도 막는다.
- 매치 시작 저장에는 실제 선택 투입까지 반영된 상태를 남겨 복구 시 지정 캡슐이 두 번 추가되지 않게 한다.
- 구버전 `{metal, holo}`는 같은 수량으로 이관하고 신규 종류는 0, 슬롯은 미해금으로 둔다. 정상 구버전 저장의 현재 머신·재고는 보존한다.
- 잘못된 구성의 비정수·음수·합계 초과·종류별 상한 위반을 정규화한다. 전체 재고 복구를 영구 구성만으로 추측하지 말고, 기존 재고가 없어서 정확히 복원할 수 없는 경우 별도 마이그레이션 정책과 로그를 둔다.

### 수정 범위

`CAPSULE_UPGRADE_SHOP`만 확장하지 않는다. 구성 정규화, 새 매치 재고 생성, 가중 투입, 풀 생성, 추첨 결과 해석·소모, 랜덤 청소, 배당금·승리 파편 합계, AI 위험 평가, 서랍·머신 통계·효과 로그·이미지 모두 종류 목록을 공유하도록 바꾼다.

신규 캡슐은 메탈·홀로그램과 구별되는 실루엣·무늬를 제공한다. 색만으로 종류를 구별하지 않고 세라믹의 안전 종료와 나머지의 재추첨 표시를 함께 사용한다. 실제 아트 제작은 후속 구현 범위다.

## 8. 우선순위와 검증 계획

### 구현 단계

1. **선행 정리:** 지속 범위 문구, 상점 저장, 종료 판정·빈 풀·탈락자 처리, 구성/실물 상태 분리. 기존 2종 회귀 검증.
2. **P1:** 세라믹 및 강화 재설정. 경제형 2종과 생존형 1종의 선택을 먼저 비교한다.
3. **P2 전반:** 시작 투입 슬롯과 완충 캡슐. 라운드 예약·시작 투입·저장 복원 검증.
4. **P2 후반:** 회수 코어. 3매치 구조에서 실제 투자 선택의 가치가 확인될 때 도입한다. 선택률이 낮으면 억지로 보상을 올리기보다 더 긴 도전 모드가 생길 때까지 보류할 수 있다.

### 비교할 구성

1차 상점에서 사용 가능한 예산이 6파편인 상황의 비교 예시다. 특정 예산이 항상 지급된다는 뜻은 아니다.

| 구성 | 지출 | 확인할 특징 |
|---|---:|---|
| 메탈 3 | 6 | 골드 보상과 일반 대체 밀도 |
| 홀로그램 2 | 6 | 아이템 보상과 보유 한도 |
| 세라믹 2 | 6 | 보상을 포기한 안전 종료 가치 |
| 메탈 1+시작 슬롯 | 6 | 밀도보다 조기 투입 보장 선택 |
| 완충 2 | 6 | 현재 위험과 다음 라운드 방어의 차이 |
| 회수 코어 3 | 6 | 2매치 전투 보상을 포기한 다음 상점 예산 |

유물 구매와도 비교한다. 6파편 황금 배당금·주머니를 선택했을 때와 동일 초기 조건으로 비교하되, 골드 수익만으로 생존형 유물의 가치를 판단하지 않는다.

### 기록할 지표

- 강화 구매·재설정·슬롯 선택률, 매치별 지출 파편.
- 구매한 강화의 실제 투입률·추첨률·재고에 남아 종료된 비율.
- 메탈 골드, 홀로그램 아이템 및 지급 실패, 세라믹 유효 종료, 완충 예약·실제 적용, 코어 승리 정산량.
- 매치 승률·승리 방식·소요 라운드와 유효 추첨당 물리적 재추첨 수.
- 파편을 버는 속도와 유물 선택률 변화. 생존 강화로 매치가 길어져 기존 경제 유물이 간접적으로 강해지는지도 확인.
- 사용자가 ‘첫 추첨 확률’과 ‘재추첨 후 위험’을 구분하는지, 영구 구성과 현재 머신을 혼동하는지.

### 필수 검증 시나리오

- 30개 전부 일반, 한 종류만 강화, 모든 종류 혼합, 일반 0개, 각 신규 상한 도달.
- 정상 시작 재고 29+머신 1, 무작위 투입과 지정 투입에서 전체 30개 보존.
- 강화 전부 소비·청소 후 다음 매치에서 구성 복원. 아이템 변환이 영구 강화 수를 늘리지 않음.
- 세라믹→더블 뽑기 두 번째 결과, 메탈 연속 재추첨 중 골드 목표 도달, 홀로그램 지급 한도.
- 완충 예약 상한·다음 라운드 한 번 적용·탈락 및 매치 종료 소멸.
- 코어 잔존 1파편과 추첨 예약 2파편의 중복 방지, 최종 매치 효과·구매 제한.
- 재설정 전후 30개 구성 유지, 파편 부족·원본 없음·대상 상한, 슬롯 원본 제거 후 선택 보정.
- 구매 직후·재설정 직후·상점에서 새로고침해 파편과 구성 복원. 승리 정산 및 시작 투입 중복 방지.
- 구버전 저장 이관, 종류별 현재 실물과 영구 구성 차이, 비정상 합계의 보정.
- 탈락자 캡슐만 있는 풀·완전 빈 풀·재추첨형만 있는 풀에서 유한 시간 내 정상 진행.

이 문서는 정적 코드 조사와 설계안이다. 실제 브라우저 플레이, 확률 시뮬레이션, 신규 효과 구현은 수행하지 않았으며 밸런스가 검증되었다는 의미가 아니다.
