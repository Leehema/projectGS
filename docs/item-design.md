# 가챠머신 서바이벌 — 아이템 현황 및 추가 기획서

작성일: 2026-09-20 · 기준: 현재 저장소 `index.html` · 상태: 구현 전 제안

관련 문서: [유물 현황 및 추가 기획서](relic-design.md)

## 1. 목적과 현재 운용 규칙

현재 구현된 아이템 14종을 실제 효과 코드 기준으로 정리하고, 대응 수단과 자원 운용 선택을 넓히는 신규 8종을 제안한다. 가격·수량은 플레이테스트 전 초안이다. 관련 문서의 신규 유물 8종도 아직 구현되지 않은 제안이며, 아래에서 기존 유물과 구분한다.

| 구분 | 현재 동작 |
|---|---|
| 획득 | 각 매치 시작 시 투시 안경 1개. 인게임 상점 구매, 매치가 끝나지 않은 라운드 종료 시 생존자별 랜덤 1개, 생존 피격 보상, 홀로그램 추첨 보상 |
| 구매 | 골드 사용. 상점에 4종 제시, 리롤 2골드. 같은 상점 단계에서 같은 종류는 1회 구매 가능하며 리롤해도 구매 기록 유지 |
| 보유 | **종류별** 기본 3개, 대용량 주머니 보유 시 5개. 전체 보유 합계 제한이 아님 |
| 사용 | 투입 순위에 따른 본인 아이템 턴에 사용. 보유한 소모품을 여러 개 사용할 수 있음. 숙성 캡슐은 사용 불가 |
| 순서 | 투입량 내림차순. 동률일 때 플레이어는 AI보다 뒤에서 사용. 후순위 참가자가 먼저 적용된 효과를 바꿀 수 있음 |
| 판매 | 기본 판매가 `floor(원가/2)`. 숙성은 추가 가치 적용. 현재 판매 함수에는 본인 아이템 턴 검사 없음 |
| 지급 한도 | 종류별 한도 미만인 아이템 중 랜덤 지급. 모든 종류가 가득 차면 지급 없음 |
| 계승 | 유물·영구 강화와 달리 아이템 재고·골드·숙성 나이는 다음 매치로 계승되지 않음 |
| AI | 플레이어와 동일한 아이템 목록에서 구매·지급·사용. 신규 아이템은 효과뿐 아니라 AI 사용 판단도 구현해야 함 |

## 2. 현재 적용 아이템 14종

가격은 골드다. ‘기본 머신’은 라운드 임시 효과를 제외한 `G.machine`, ‘임시’는 해당 라운드의 효과 상태 `ctx`를 의미한다.

| 아이템 / ID | 가격 | 실제 효과 | 중첩·제약 |
|---|---:|---|---|
| 투시 안경 / `peek` | 4 | 현재 풀에서 첫 추첨 결과를 정해 저장하고 확인 | 결과가 유지되는 동안 다시 쓰면 같은 결과. 이후 풀 변경 효과가 예측을 초기화하거나 수정할 수 있음 |
| 더블 트랩 / `double` | 3 | 상대의 이번 라운드 실제 기본 투입+페널티 투입량만큼 임시 일반 캡슐 추가 | 재고 소모 없음. 반복 사용은 같은 기준량을 더하며 매번 전체가 2배가 되는 것은 아님 |
| 캡슐 청소 / `purge` | 4 | 기본 머신의 빈·일반·메탈·홀로그램에서 무작위 최대 6개 제거 | 임시 추가분 제외. 제거분 재고 반환 없음. 현재 매치에서 지속 |
| 빈 캡슐 투하 / `emptydrop` | 3 | 임시 빈 캡슐 6개 추가 | 반복 시 합산. 내 위험뿐 아니라 상대 위험도 낮춤 |
| 더블 뽑기 / `doubledraw` | 3 | 이번 라운드의 유효 추첨을 최대 2회로 설정 | 불리언 효과라 반복 사용해도 3회 이상이 되지 않음. 첫 추첨에서 매치가 끝나면 종료. 강화 캡슐 등의 재추첨은 별도 |
| 하트 실드 / `shield` | 4 | 이번 라운드 일반 캡슐 피해 1회를 막음 | 같은 사람에게 반복 사용해도 보호 횟수 누적 안 됨. 불사조보다 우선. 방어한 캡슐은 소모 처리 |
| 함정 캡슐 / `trap3` | 3 | 상대에게 임시 일반 캡슐 **2개** 추가 | 반복 시 합산. 설명의 ‘몰래’와 달리 로그·사용 팝업에 대상과 효과 표시 |
| 삼중 부적 / `ward3` | 3 | 내 일반 캡슐을 최대 **2개** 빈 캡슐로 계산 | 기본+임시 일반 수량 안에서 적용. 강화 캡슐 제외. 반복 시 보호 수량 합산. 뒤바꿈 전에 계산 |
| 캡슐 수당 / `matchgold` | 3 | 이번 라운드 실제 기본 투입+페널티 투입량만큼 골드 획득 | 더블 트랩·함정의 임시 추가량은 `roundCapsuleAdds`에 기록되지 않아 제외. 반복 사용마다 동일 기준량 지급 |
| 골드 캡슐 / `gold10` | 3 | 즉시 **8골드** 획득 | ID와 달리 10골드 아님. 구매 후 사용하면 순증가 5골드 |
| 캡슐 뒤바꿈 / `swap` | 3 | 사용자와 대상의 유효 일반 캡슐 수를 이번 라운드 교환 | 메탈·홀로그램 제외. 교환 쌍 하나만 저장하므로 후속 사용이 기존 쌍을 덮어씀. 저장된 일반 투시 결과도 변경 |
| 숙성 캡슐 / `aging` | 3 | 보유 중 새 라운드 시작마다 판매가 +3. 판매가 `1+3×숙성 나이` | 나이를 개별 캡슐이 아닌 종류 단위로 공유. 기존 보유분이 있으면 새 획득분도 같은 나이 적용. 전량 판매 시 초기화 |
| 메탈 캡슐화 / `metalcap` | 5 | 기본 머신의 내 일반 최대 3개에 각각 50% 확률로 메탈 전환 | 추첨 시 소유자 +5골드 후 재추첨. 아이템 전환은 매치 내 유지이며 영구 강화 수를 늘리지 않음 |
| 홀로그램 캡슐화 / `holocap` | 5 | 기본 머신의 내 일반 최대 3개에 각각 50% 확률로 홀로그램 전환 | 추첨 시 소유자 랜덤 아이템 후 재추첨. 한도 때문에 보상 없이 재추첨할 수도 있음 |

### 설명·동작 정리 및 선행 점검

아래는 코드로 확인한 현재 동작과 수정 제안이다. 이번 문서 작업에서 수정하지 않았다.

1. **명칭과 문구:** 삼중 부적은 ‘이중 부적’으로 표시명을 바꾸거나 효과를 3개로 바꾸는 선택이 필요하다. 우선은 실제 수치 2개를 유지하고 이름을 수정하는 안을 권장한다. 함정 캡슐의 ‘몰래’는 삭제한다. 기존 저장 호환을 위해 내부 ID는 유지한다.
2. **수당 문구:** ‘이번 라운드 재고에서 투입한 캡슐 수(페널티 포함)만큼 골드 획득’으로 수정한다. 임시 캡슐까지 지급 대상으로 바꾸는 것은 별도의 밸런스 변경이다.
3. **실드·더블 뽑기 낭비:** 이미 활성화된 상태에서 같은 효과를 다시 사용하지 못하게 UI와 실행부 양쪽에 검사한다.
4. **숙성 단위:** 현재는 개별 보유 기간과 판매가가 일치하지 않는다. 종류 공통 숙성도를 정식 규칙으로 명시하거나 개별 획득 라운드를 저장하는 방식으로 변경해야 한다. 기존 구조에 다른 아이템을 숙성 캡슐로 바꾸는 기능을 바로 추가하면 오래된 나이를 물려받을 수 있다.
5. **예측 상태:** 투시는 참가자별이 아닌 `ctx.peekedOutcome` 하나를 공유한다. 여러 참가자의 투시, 뒤바꿈 반복, 풀 변경 후 예측 유효성을 확인해야 한다.
6. **임시 캡슐 소모:** 추첨 시 일반 캡슐은 기본 머신에서 우선 차감하지만 임시 추가량은 차감하지 않는다. 빈 결과도 기본 빈 캡슐만 차감하며 임시 빈 캡슐·부적으로 생성된 빈 결과의 출처는 구분하지 않는다. 더블 뽑기에서 어떤 캡슐이 남는지에 영향을 준다.
7. **AI 판단:** 현재 위험도 계산에 안전한 강화 캡슐도 포함한다. 일부 종류는 별도 평가식 없이 작은 무작위 점수만 받아 사용될 수 있으며, 반복 실드·더블 뽑기 같은 무효 소비도 가능하다. 신규안에는 명시적인 사용 가능 조건과 가치 평가를 추가한다.
8. **골드 승리 시점:** 즉시 골드·판매·메탈 보상 직후 공통 승리 검사가 없다. 유물 기획서의 승리 판정 정리안과 함께 다룬다.

## 3. 추가 설계 방향

현재는 직접 추가·방어·골드 지급이 충분하다. 특히 3골드로 8골드를 받는 골드 캡슐이 있어, 단순 소액 골드 아이템을 더하면 선택 가치가 낮다. 신규안은 다음 빈자리를 채운다.

- 이미 걸린 임시 함정을 제거하는 대응.
- 머신의 위험을 줄이는 대신 승리 파편을 포기하고 재고를 확보하는 선택.
- 자신의 생존율과 상대 제거 가능성을 함께 바꾸는 공용 풀 조작.
- 강화 캡슐의 수보다 보상 종류를 조절하는 선택.
- 사용 순위에 따라 상대 행동에 대응하는 소모품.

모든 신규안은 기존 골드·아이템 턴 구조를 사용한다. 새 재화, 턴 중 실시간 반격 입력, 상대 인벤토리 강탈은 도입하지 않는다.

### 4.1 함정 해제기

**상점 문구:** “이번 라운드 내게 추가된 임시 일반 캡슐을 최대 4개 제거합니다.”

- 더블 트랩·함정 캡슐이 만든 `tempCaps[user.id]`에서만 제거한다. 기존 일반·강화 캡슐과 최소 투입 페널티에는 영향이 없다.
- 제거 가능량이 0이면 사용 불가·미소모. 반복 사용 시 남은 양에 적용하며 재고로 돌려주지 않는다.
- 뒤바꿈 중에도 **내 소유자로 기록된 임시 추가분**을 제거한다. 실제 추첨 위험이 누구에게 줄어드는지 사용 전에 표시한다.
- 추첨 풀이 바뀌므로 저장된 투시 결과는 초기화한다.
- **AI:** 자신의 현재 유효 피격 확률이 감소할 때 사용한다. 뒤바꿈 때문에 상대만 유리해지는 경우 보류한다.
- **차별점:** 실드는 피해 1회 방어, 부적은 위험을 빈 결과로 변환한다. 해제기는 임시 위험만 제거하며 이미 지나간 상대 턴에 대응한다.
- **검증:** 임시 0/2/6개, 형벌만 있는 경우 사용 불가, 뒤바꿈 적용 상태에서 제거 대상 확인.

### 4.2 회수 자석

**상점 문구:** “머신 속 내 일반 캡슐을 최대 2개 회수해 보유 재고로 돌려놓습니다.”

- `machine.capsules[user.id]`를 줄이고 같은 양만큼 `capsuleStock.normal`을 늘린다. 임시·강화 캡슐 제외.
- 머신에 1개면 1개 회수, 0개면 사용 불가. 현재 구조의 재고 한도 30개를 넘지 않는 회수량으로 제한한다.
- 해당 라운드 순위·이미 받은 골드·수당 기준인 투입 기록은 되돌리지 않는다. 이후 재투입은 다음 라운드 베팅에서 가능하다.
- 투시 결과를 초기화한다. 영구 강화 배분은 변경하지 않는다.
- **기존 유물:** 배당금 기준과 승리 파편이 줄어드는 대가가 있다. 강철 사슬로 높아진 최소 투입량을 다음 라운드에 감당할 재고를 확보한다.
- **제안 유물:** 비상 배출 레버·응급 키트는 제거 후 재고를 주지 않으므로 목적이 다르다. 함께 보유하면 일반 캡슐 고갈을 확인한다.
- **AI:** 위험 감소와 다음 라운드 재고 부족을 평가한다. 머신+재고의 실제 캡슐 총량은 회수 전후 동일해야 한다.
- **검증:** 재고 29개에서 회수 상한, 일반 0개, 부적·뒤바꿈 동시 사용, 파편 계산 감소.

### 4.3 공회전 필터

**상점 문구:** “머신에 원래 들어 있는 빈 캡슐을 최대 4개 제거합니다. 모두의 일반 캡슐 추첨 확률이 높아집니다.”

- 기본 머신의 빈 캡슐만 제거한다. 빈 캡슐 투하의 임시분, 부적의 빈 결과는 제거하지 않는다.
- 기본 빈 캡슐이 0개면 사용 불가. 제거는 현재 매치에 지속하고 투시를 초기화한다.
- **차별점:** 캡슐 청소와 달리 상대 일반 캡슐이나 강화 캡슐을 제거하지 않는 공세적 선택이다. 자신도 더 위험해진다.
- **조합:** 실드+필터+더블 뽑기는 상대 제거를 노리지만 실드는 피해 1회만 막는다. 빈 캡슐 투하로 생성한 6개를 다시 제거하는 조합은 성립하지 않는다.
- **AI:** 현재 풀에서 상대의 유효 일반 수가 자신의 유효 일반 수보다 많을 때 우선 고려하고, 목숨 1·실드 없음이면 평가를 낮춘다.
- **검증:** 기본 빈 2개만 제거, 임시 빈 유지, 부적 유지, 빈 캡슐만 있던 풀이 0이 되면 안전한 무추첨 처리.

### 4.4 위상 변환기

**상점 문구:** “머신 속 내 메탈 캡슐 1개를 홀로그램으로, 또는 홀로그램 1개를 메탈로 바꿉니다.”

- 사용 전에 두 방향 중 선택한다. 원본 종류가 없으면 해당 방향 비활성화, 둘 다 없으면 사용 불가.
- 성공률 100%, 한 번에 1개. 기본 머신의 내 캡슐만 바꾸고 임시 캡슐·재고·영구 강화 수는 변경하지 않는다.
- 총 캡슐 수는 보존한다. 결과 종류가 바뀌므로 투시를 초기화한다.
- **차별점:** 메탈·홀로그램 캡슐화는 위험한 일반 캡슐을 안전한 강화 캡슐로 바꾼다. 이 아이템은 이미 안전한 캡슐의 보상 유형만 바꾼다.
- **제안 유물:** 금속 공명기·홀로그램 카탈로그와 선택적으로 연계. 정밀 주입기는 확률 강화 전용이므로 영향 없음.
- **AI:** 목표 골드에 가까우면 메탈 방향, 사용 가능한 아이템이 부족하면 홀로그램 방향. 전 종류가 가득 차면 홀로그램 방향을 피한다.
- **검증:** 취소 시 미소모, 방향별 재고 검증, 전환 전후 총량 동일, 다음 매치 영구 강화 배분 유지.

### 4.5 단발 고정핀

**상점 문구:** “현재 적용된 더블 뽑기를 해제해 추첨을 1회로 되돌립니다. 이후 더블 뽑기는 다시 적용될 수 있습니다.”

- 현재 `doubleDraw=true`일 때만 사용 가능. `false`로 변경하고 소모한다.
- 이후 차례의 참가자가 더블 뽑기를 쓰면 다시 활성화된다. 추첨 횟수를 한 라운드 내내 잠그는 효과는 아니다.
- 메탈·홀로그램·탈락자 캡슐의 무효 결과 재추첨은 막지 않는다. 첫 추첨 풀은 같으므로 투시는 유지한다.
- **차별점:** 실드와 달리 특정 참가자를 보호하지 않고 두 번째 유효 추첨 자체를 없앤다. 사용 순위가 가치를 결정한다.
- **AI:** 두 번째 추첨이 생존에 불리하거나 골드 우세를 지키고 싶을 때 사용한다. 본인 턴에서 고정핀 후 더블 뽑기를 연달아 소비하는 모순 행동을 막는다.
- **검증:** 더블 없음에서 미소모, 더블→고정핀→더블, 강화 재추첨 유지.

### 4.6 아이템 교환권

**상점 문구:** “이 교환권과 다른 아이템 1개를 소모하고, 제시된 최대 3종 중 아이템 1개를 받습니다.”

- 다른 보유 아이템을 먼저 선택한다. 교환권 자체와 숙성 캡슐은 재료 및 보상 후보에서 제외한다. 재료와 같은 종류도 후보에서 제외한다.
- 보상 후보는 소모 후 종류별 한도를 지킬 수 있는 아이템에서 중복 없이 최대 3종을 추출한다. 후보가 0종이면 사용 불가, 1종이면 자동 교환한다.
- **무료 후보 확인 방지:** 재료 선택까지는 취소 가능. 교환 실행 시 두 아이템을 소모하고 후보를 확정한 뒤에는 취소·후보 재추출 불가. 확정 후보 중 하나를 받아야 한다.
- 가격 차이에 따른 골드 정산은 없다. 2개를 1개로 바꾸는 손해 대신 필요 없는 재고를 원하는 효과에 가깝게 바꾼다.
- **기존 유물:** 주머니의 종류별 한도 반영. **제안 유물:** 홀로그램 카탈로그와 후보 선택 UI를 공유할 수 있지만 발동 원인과 후보 규칙은 분리한다.
- **AI:** 이미 활성화된 실드·더블 뽑기의 여분 등 현재 가치가 낮은 것을 재료로 삼는다. 보상을 고른 뒤 같은 턴에 사용 가능하다.
- **검증:** 후보 0/1/3종, 중복 클릭, 단계별 취소, 숙성 나이 불변, 확정 후 보유 수 변화 처리.

### 4.7 보상 봉인 스티커

**상점 문구:** “이번 라운드 상대의 첫 메탈·홀로그램 캡슐 보상 1회를 막습니다. 해당 캡슐의 결과 무효화와 재추첨은 유지됩니다.”

- 살아 있는 상대를 지정한다. 기본 머신에 해당 상대의 강화 캡슐이 최소 1개 있을 때만 사용 가능하다.
- 메탈과 홀로그램을 합쳐 첫 1회에 적용한다. 강화 캡슐을 일반 피해 캡슐로 바꾸지 않는다.
- 동일 대상에게 중복 예약 불가. 다른 참가자가 먼저 봉인해도 추가 사용 불가. 추첨되지 않은 예약은 라운드 종료 시 소멸한다.
- 메탈이면 기본 5골드와 제안 유물 공명기의 추가 보상 모두 지급하지 않는다. 보상이 봉인된 추첨은 공명기의 보너스 사용 횟수도 소모하지 않는 안으로 통일한다.
- 홀로그램이면 아이템 지급 및 제안 유물 카탈로그의 선택창을 생략한다. 뒤바꿈은 강화 캡슐 소유자에 영향을 주지 않는다.
- **AI:** 목표 골드가 가까운 메탈 보유 상대를 우선 평가한다. 현재 AI는 영구 강화 없이 시작하므로 상대 강화 확보가 늦으면 카드 가치가 낮을 수 있다.
- **검증:** 메탈→홀로 연속 추첨에서 첫 보상만 봉인, 강화 없는 대상, 동일 대상 중복, 재추첨 유지.

### 4.8 역추적 태그

**상점 문구:** “이번 라운드 이후 나에게 더블 트랩·함정 캡슐을 성공적으로 사용한 첫 상대에게 임시 일반 캡슐 2개를 추가합니다.”

- 본인 아이템 턴에 예약한다. 이미 받은 함정에는 소급 발동하지 않는다. 살아 있는 후순위 참가자가 없으면 사용 불가.
- 예약 후 실제로 나에게 1개 이상 임시 캡슐을 추가한 첫 더블 트랩·함정 캡슐만 대상이다. 뒤바꿈·봉인·최소 투입 페널티는 발동시키지 않는다.
- 원래 공격은 그대로 적용한 뒤 공격자의 임시 일반 캡슐 +2. 반격 자체는 다른 역추적을 발동시키지 않는다.
- 본인에게 태그가 이미 예약되어 있으면 추가 사용 불가. 한 라운드에 본인 태그가 한 번 발동한 뒤에도 재예약 불가. 발동하지 않으면 라운드 종료 시 소멸한다.
- **차별점:** 함정 해제기는 후순위 대응, 태그는 선순위 억제다. 상대가 공격하지 않으면 효과 없이 소모된다.
- **AI:** 후순위 상대가 있고 자신의 위험이 높을 때 고려한다. 비공개 인벤토리를 읽는 전용 판단은 만들지 않고 공개 상황을 사용한다.
- **검증:** 실제 추가 0개인 더블 트랩, 이미 받은 공격, 태그 간 무한 반격 방지, 발동 후 함정 해제기로 반격분 제거.

## 5. 공통 구현 규칙

### 사용 검증과 소비

- 플레이어·AI 공통 `canUseItem` 판정을 둔다. 턴·재고·대상 생존·효과 적용 가능량·중복 예약을 확인한 후 소모한다.
- 효과 실행은 실제 성공 여부와 실제 수량을 반환하도록 정리한다. 대상 없음·수량 0·중복 효과라면 아이템을 잃지 않는다.
- 새 아이템은 기본적으로 반복 사용 가능하되 각 상세의 중복 제한을 따른다. 기존 아이템 전체를 ‘종류별 턴당 1회’로 바꾸지는 않는다.
- 봉인 대상 집합, 태그 소유자·발동 완료 집합은 라운드 임시 상태에 둔다. 매치 계승 대상이 아니다.

### 추첨 풀과 예측

- 해제기·회수·필터·변환기는 풀이나 결과 종류를 바꾸므로 투시 예측을 초기화한다. 고정핀·교환권·봉인 예약·태그 예약은 풀을 즉시 바꾸지 않아 유지한다. 태그가 실제 반격 캡슐을 만들면 초기화한다.
- 부적과 뒤바꿈은 기본 머신 변경 뒤에 현재 규칙대로 다시 계산한다. 화면 확률과 실제 추첨이 동일한 풀을 사용해야 한다.
- 빈 풀에서는 가중 추첨 함수를 호출하지 않고 피해 없는 결과로 처리한다. 필터 등으로 빈 풀이 생길 수 있다.
- 임시·기본 캡슐 출처에 따른 소모 규칙을 먼저 확정한다. 권장안은 추첨 후보에 출처와 실제 소유자, 유효 피해 대상을 함께 유지하여 뽑힌 실물을 정확히 차감하는 것이다. 부적으로 빈 취급된 캡슐도 해당 원본을 차감한다. 이는 **현재 코드와 다른 수정 제안**이다.

### AI와 UI

- AI 평가에 현재 유효 일반 캡슐의 피격 확률을 사용한다. 강화 캡슐은 피해 위험과 보상 가능성을 분리해 평가한다.
- 효과 없는 사용을 먼저 제외하고, 예상 이득이 있는 후보만 선택한다. 작은 무작위 점수가 무효 사용을 허용하지 않게 한다.
- 자석·필터·해제기는 사용 전 실제 변화량을 표시한다. 변환기는 방향 선택, 교환권은 재료 및 후보 선택 UI가 필요하다.
- 태그·봉인은 대상 패널에 남은 예약 상태를 표시한다. 반격 로그에는 공격자와 반격 원인을 함께 출력한다.
- 현재 `ITEM_ICON_CELL`은 14종을 4×4 스프라이트 좌표에 매핑한다. 신규 8종을 포함한 22종은 한 장의 16칸을 초과하므로 두 번째 시트와 시트별 매핑을 추가하거나 전체 좌표 체계를 확장해야 한다. 기존 14종의 좌표를 무심코 바꾸지 않는다.

### 저장과 공통 지급 풀

- 현재 저장은 라운드 체크포인트 기반이다. 신규 아이템 수량은 기존 `items`에 저장되지만, 선택 도중 임의 시점 재개는 별도 기능이다. 이번 안의 기본은 라운드 시작 복귀를 유지하는 것이다.
- 중간 저장을 도입한다면 교환권 소비 여부·확정 후보·선택 결과를 함께 저장해야 한다. 후보만 확인하고 다시 받는 경로를 막는다.
- `ITEMS`에 추가하면 상점뿐 아니라 라운드 보너스·피격·홀로그램 보상에도 자동으로 들어간다. 신규 8종을 모두 넣으면 풀이 14→22종으로 늘어 기존 핵심 아이템 획득 빈도가 낮아진다.
- 최초 P1만 추가하면 총 18종이다. 일단 기존 무작위 지급 규칙을 유지하되, 상황 한정 아이템이 쌓이는 빈도를 측정한다. 이후 획득처별 가중치를 도입하더라도 획득 후 사용 조건과는 분리한다.

## 6. 가격·밸런스 및 구현 순서

### 가격 판단

- 기존 가격대 3~5골드를 유지한다. 자석은 영구적인 위험 감소와 재고 회복을 함께 제공해 4골드, 한정 대응·전환은 3골드로 시작한다.
- 봉인은 상대의 최대 5골드 이상 또는 아이템 보상을 막을 수 있어 4골드다. 강화 캡슐이 뽑히지 않으면 손해이므로 등장 대비 실제 사용률을 확인한다.
- 무료 지급이 많아 구매 가격만으로 강도를 제어할 수 없다. 효과 수량·중복 제한·보상 풀 구성이 함께 중요하다.
- 단골 도장·정밀 주입기 등은 제안 단계다. 기존 유물 조합 검증과 제안 유물 동시 도입 검증을 분리한다.

### 단계

1. 설명 불일치·중복 소비 방지·빈 풀·임시 캡슐 소모 기준을 정리하고 기존 14종 회귀 검증.
2. P1 함정 해제기 → 공회전 필터 → 회수 자석 → 위상 변환기 구현. 각 효과와 AI 규칙을 같이 연결.
3. P2 단발 고정핀 → 역추적 태그 → 보상 봉인 스티커 구현. 후순위 대응과 강화 보상 순서 검증.
4. 아이템 교환권의 선택 UI 및 소비 원자성 구현. 제안 유물 카탈로그를 구현한다면 후보 선택 UI를 공유.

|---|---|
| 획득·구매·사용·판매 비율 | 상황 한정 아이템이 판매 전용으로 쌓이는가? |
| 획득부터 사용까지 라운드 수 | 짧은 매치에서 발동 기회를 얻는가? |
| 자석 사용 후 재고와 파편 변화 | 생존과 보상 사이의 선택이 유지되는가? |
| 필터 사용 후 자신·상대 피격 | 공세 효과가 특정 조합에서 지나치게 안전한가? |
| 고정핀·태그의 투입 순위별 가치 | 마지막 순위 또는 첫 순위가 항상 유리해지는가? |
| 봉인 성공률과 막은 보상량 | 강화 기반 선택이 무력화될 정도인가? |
| 교환 재료·선택 후보·연속 교환 수 | 특정 효과만 얻는 반복 순환이 생기는가? |
| 기존 실드·골드·강화 아이템 획득률 | 풀 확대만으로 게임 난도가 크게 변하는가? |

현재 저장소에 자동 밸런스 시뮬레이터는 없으므로 우선 수동으로 매치별 단일 효과와 주요 조합을 확인한다. 후속 자동 비교에서는 같은 초기 상태·난수 시드로 기존 14종과 확장 풀을 비교한다. 이 문서는 측정 결과가 아닌 실행 계획이다.

## 7. 필수 검증 시나리오

- 기본 일반·임시 일반·강화·기본 빈·임시 빈이 섞인 풀에서 변경 대상만 수정되는지 확인.
- 더블 트랩→해제기, 함정→부적→해제기, 뒤바꿈→자석으로 실제 피해 대상과 실물 소유자 구분.
- 필터로 기본 빈 전량 제거, 완전 빈 풀, 더블 뽑기 첫 결과 뒤 두 번째 풀 재계산.
- 투시 후 신규 풀 변경 효과 사용 시 예측 초기화. 풀 불변 효과는 기존 예측 유지.
- 더블→고정핀→다른 참가자의 더블, 실드 활성 상태의 중복 사용 방지.
- 메탈→홀로 변환 후 보상 종류 변경, 봉인된 첫 강화 추첨 후 두 번째 강화 보상 정상 지급.
- 태그 예약 전 공격 제외, 실제 추가 0개 공격 제외, 반격 간 연쇄 발동 금지.
- 교환권 후보 확정 전 취소와 확정 후 중복 클릭, 아이템 한도 및 숙성 나이 불변.
- 플레이어와 AI에 동일한 사용 가능 조건 적용. AI의 불필요한 반복 소비와 상충 효과 연속 사용 확인.
- 체크포인트 복귀에서 재고·머신·소유 아이템 보존. 새 매치에서 소모품 초기화.
- 기존 골드 지급·판매·메탈 보상이 목표 금액을 채울 때 승리 판정 정리안에 맞게 종료.
